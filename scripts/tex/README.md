# Проверки на формулите (KaTeX)

Всички уроци са с формули в KaTeX (преминаването завърши на 09.10.2026). Новите уроци пишат формулите
направо с `<Tex>` и `$…$`.

```bash
node scripts/tex/validate.mjs src/**/*.tsx        # всяка формула се рендира с KaTeX без грешка
node scripts/tex/check-quizzes.mjs src/**/*.tsx   # верният отговор е сред вариантите и не се откроява
sh scripts/tex/check-all.sh [страница…]           # в браузъра при 1280 и 390 px (dev сървър на :5179)
```

`check-all.sh` отваря всички решения с `expand.js` и пуска `check.js` на страницата: брои формулите и намира
`.katex-error`, останали `$…$` и формули, които излизат извън екрана. Двата скрипта може да се пуснат и
поотделно: `agent-browser eval --stdin < scripts/tex/check.js`.
